# Personal Portfolio Website

A responsive full-stack personal portfolio website developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB Atlas.

This project was created as part of the Full-Stack Web Development Internship. The portfolio showcases personal information, technical skills, projects, and provides a contact form that allows visitors to send messages. Submitted messages are stored in a MongoDB Atlas database through a Node.js and Express backend.

## Features

* Responsive and modern user interface
* Navigation bar with smooth scrolling
* Hero section with personal introduction
* Skills section with progress bars
* Projects showcase section
* Contact form with backend integration
* MongoDB Atlas database connectivity
* Mobile-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* CORS
* Dotenv

## How to Run

1. Clone the repository.
2. Install dependencies using:
   npm install
3. Configure the `.env` file with your MongoDB Atlas connection string.
4. Start the server:
   node server/server.js
5. Open the application in your browser.

## Project Outcome
This project demonstrates front-end web design, responsive layouts, backend development using Express.js, database integration with MongoDB Atlas, and full-stack web development concepts.
